How it works. Kalshi prices come from the Mac scanner (public Kalshi API, every 5 min) — Kalshi blocks browser requests, so its prices arrive as a data file in this repo. Novig prices come from Novig's public catalog, refreshed with the dashboard data (every 5 min). Polymarket prices are fetched LIVE in your browser straight from Polymarket's Gamma API (one batched call) — click any Polymarket price to see its live CLOB order book. Book prices are DraftKings via ESPN, as captured by the Kalshi scan. The "Best book" column shows the best price across the books in the dashboard data file. "Best" = lowest cost to buy $1 of payout on that exact outcome at that exact line; when Polymarket doesn't offer the book's exact line, its nearest lines are shown separately and never compared as if they were the same bet. Polymarket prices exclude its trading fee; Kalshi's 7% fee on winnings is not reflected in the ask. The Bet button copies a ticket ("BET — venue: game — market @ price — via Chet") to paste to Chet in chat — it places nothing. This page reads the same live data files as the dashboard, so it stays fresh on the same cadence with no republishing per cycle. One game per page, no heavy assets — built to stay fast with dozens of live games open at once.
