# Virtual Card Lab v4.5

A high-performance, browser-based simulator for card mechanics, stack maintenance, and shuffle tracking. Designed specifically for practicing advanced sleight-of-hand concepts like the **Faro Shuffle**, **Si Stebbins Stack**, and the **Gilbreath Principle**.

## 🃏 Core Features

### 1. Advanced Shuffle Simulations

* **Faro Shuffles:** Perfectly execute **In-Faro** and **Out-Faro** shuffles to track card positions across multiple iterations.
* **Gilbreath Principle:** A mathematical simulation of a reversed-half riffle to demonstrate Gilbreath properties.
* **Fisher-Yates Random Shuffle:** Instantly randomize the deck to test your ability to re-stack from a "shuffled" state.
* **Manual Cuts:** Rotate the deck at any specific index to simulate spectator cuts without breaking stack logic.

### 2. Pre-Loaded Professional Stacks

Quickly reset the lab to any of the following standard or custom arrangements:

* **NDO (New Deck Order):** The factory standard.
* **Si Stebbins:** A classic mathematical stack (3C top).
* **Mnemonica:** Juan Tamariz's legendary memorized stack.
* **Custom CHASED Order:** A specialized $Q, J, 2...$ sequence following the Club-Heart-Spade-Diamond rotation.

### 3. Mechanic's Toolkit

* **Dynamic Cheat Sheet:** A 13x4 grid displaying the exact state of the deck with suit symbols (♣, ♥, ♠, ♦) and real-time position indexing.
* **Live Move History:** A persistent log on the sidebar that records every swap, shuffle, and cut for post-session review.
* **Card Search & Highlight:** Instantly locate any card (e.g., "KH" or "3S") within the current stack.
* **Persistent Memory:** Save your current deck state to `localStorage` so you can close your browser and resume your practice session later.

## 🛠️ Installation & Usage

This project is a single-file application. No complex installation or dependencies are required.

1. **Download/Clone:** Save the `index.html` file to your local machine.
2. **Run:** Open the file in any modern web browser (Chrome, Firefox, Safari, or Edge).
3. **GitHub Pages:** Push this to a GitHub repository and enable "Pages" in the settings to access your lab from a mobile device or tablet at the card table.

## 🖱️ Controls

* **Click to Swap:** Click any two cards to manually swap their positions.
* **Search:** Type into the search bar to highlight specific cards.
* **Reset:** Use the gold buttons to return to a known stack.
* **Logs:** Use the 'Clear' button in the sidebar to reset your session history.
