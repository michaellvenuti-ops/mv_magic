What it watches

Five public sources, diffed every run, plus an announcement sweep:

  • Kalshi API changelog RSS — docs.kalshi.com/changelog
  • Polymarket docs changelog — docs.polymarket.com/changelog/predictions (59 entries tracked)
  • Polymarket US fee schedule — docs.polymarket.us/fees
  • Polymarket Gamma tags — 2,000 tags (new tags = possible new market categories)
  • Kalshi series list — 17,126 series (incremental poll, full refresh weekly)
  • Announcement sweep — @Kalshi, @Polymarket, @PolymarketUS, the Risk Takers community, Prediction News Network, RG.org

It flags:

  • (a) New liquidity / rewards / rebate programs on Kalshi or Polymarket (US or international) — with the exact terms and the expiry date.
  • (b) Newly listed market categories — a sport or market with no makers yet (the ITF-tennis pattern). A new tag or series is a candidate only; it is verified as a real category before any alert.
  • (c) New venues — a new exchange, or Polymarket/Kalshi launching in a new market.
  • Material changes to a tracked program — extension, early end, or terms change.

It does not alert on API deprecations, technical changelog noise, routine listings inside an existing category, fee changes with no program attached, or anything already caught below.
