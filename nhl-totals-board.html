NHL Totals Board

Daily NHL total leans from @linemakersports' shots-times-save% system. Updated every morning; graded the next morning.

How it works

Predicted total for a game = [away shots-on-goal/game x (1 - home team save%)] + [home shots-on-goal/game x (1 - away team save%)], using each team's season-to-date stats. Frank's example: 29 shots x .900 save% = 26.1 expected saves, leaving ~3 expected goals for that team.

Save% choice: each team's TEAM save% (all goalies combined: total saves / total shots against), because the reel's whiteboard factor reads "Opposing Goalies Save %" (plural). Caveat: a backup starter with a very different save% changes the number — check the announced starter before placing.

Threshold is CHET'S DISPLAY CHOICE, NOT Frank's claim — the reel states no threshold. A game is flagged OVER only when the predicted total sits at least 1.0 goal ABOVE the book total, and UNDER only when it sits at least 1.0 goal BELOW it. Games inside the 1.0 band are shown but never flagged.

Early-season caveat: season-to-date stats are noisy in the first weeks of the season, when teams have played only a handful of games.
